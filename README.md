# 日常打卡 · Daily Check-in

一个以本地存储实现的微信小程序，用于选择习惯、记录每日完成情况、回看统计和保存阶段成就。

## 功能

- 今日、统计、习惯管理三个页面。
- 学习、工作、健身、生活四类共22项固定预设，支持自定义习惯、图标和颜色。
- 点击卡片打卡，再次点击取消；支持删除习惯及其对应记录。
- 近7天、近30天完成率，按周一对齐的8周日历。
- 区分当前连续、历史最长、累计打卡次数和活跃天数。
- 14条成就规则。解锁信息独立保存在本地；存储写入成功且未清除时，不因当前指标回落而撤销。

## 运行

1. 克隆或下载本仓库。
2. 用微信开发者工具导入仓库根目录，项目类型选择小程序。
3. `project.config.json` 中的 `touristappid` 是公开示例值。请选择你有权使用的 AppID，或使用开发者工具支持的测试/游客方式；发布体验版、正式版需要自己的小程序账号和相应权限。
4. 编译后查看“今日”“统计”“习惯”三个页面。

项目没有 npm 运行时依赖，无自建后端和业务模型调用。工程基础库配置值为3.0.0；该值不代表已完成所有设备和基础库版本的兼容验证。

## 规则自检

安装 Node.js 后，在仓库根目录执行：

```sh
node tools/selftest.js
```

项目提供12组共96项断言，覆盖日期、连续天数、完成率、日历、汇总、成就、解锁保留及预设数据。测试结果与覆盖边界见 [测试说明](docs/TESTING.md)。不需要安装 npm 包。

## 示例数据与限制

首次使用时会初始化6项习惯及固定偏移的示例记录。90次打卡、23个活跃日、历史最长19天、8/14成就等均为演示数据，不是真实用户效果。

- 记录只保存在本机，清除缓存或更换设备可能丢失。
- 示例数据和个人记录尚未分离，空数据可能触发重新初始化。
- 保存失败反馈和恢复机制需要完善，删除习惯跨多个存储操作，不具备事务回滚。
- 个别界面标签仍需统一：近7天是滚动窗口；当前连续与历史最长属于不同指标。
- 尚无完整真机、性能、长期使用和用户效果验证。
